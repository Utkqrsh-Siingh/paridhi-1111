# A Wish at 11:11 — For Paridhi 💚

A dreamy, green-themed interactive proposal website for Paridhi, with a personalized 11:11 letter and readable dark-green text on a cream paper card.

## Preview locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub, for example `paridhi-1111`.
2. Upload `index.html` and `README.md` from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show your website URL, usually:
   `https://YOUR-USERNAME.github.io/paridhi-1111/`

Share that URL with Paridhi. 💚

Tip: You can change the text in `index.html` before uploading. The website is self-contained and does not need a build step or external libraries.
